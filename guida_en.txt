Program Guide

File:
New: Create a new document (Ctrl+N).
Open: Open text files, PDFs, EPUBs, MP3s, and other supported formats (Ctrl+O).
Save: Save the document (Ctrl+S).
Save As: Save with a new name.
Save All: Save all documents (Ctrl+Shift+S).
Recent Files: Open a recent file.

Multimedia Files:
When you open a multimedia file (MP3, WAV, MP4, AVI), Sonarpad becomes an audio player.
Keyboard controls:
- SPACE: Play / Pause.
- RIGHT ARROW: Fast forward 1 minute.
- LEFT ARROW: Rewind 1 minute.
- UP ARROW: Increase volume.
- DOWN ARROW: Decrease volume.
- +: Increase playback speed.
- -: Decrease playback speed.
- SHIFT +: Increase the pitch.
- SHIFT -: Decrease the pitch.
- CTRL+I: Announce playback time.
- CTRL+T: Go to a specific time.
- CTRL+B: Insert a bookmark at the exact time.

Current media splitting:
When a local multimedia file is open, the Split media command is available from the Playback menu.
You can split the file in two ways:
- Into parts: choose how many parts to split the file into, from 2 to 999.
- By time: choose the duration of each part, using seconds, mm:ss, or hh:mm:ss format.
This feature is available for local files, such as MP3, MP4, and other supported formats.
During splitting, Sonarpad shows the progress percentage.
When the process is completed, the resulting files are saved in the folder indicated by the program.

Edit:
Undo: Undo the last operation (Ctrl+Z).
Cut: Remove selected text and copy it to clipboard (Ctrl+X).
Copy: Copy selected text to clipboard (Ctrl+C).
Paste: Paste clipboard content into document (Ctrl+V).
Select All: Select all text (Ctrl+A).
Find: Search text in the document (Ctrl+F).
Find in Files: Search text across multiple files (Ctrl+Shift+F).
Find Next: Find next occurrence (F3).
Replace: Find and replace text (Ctrl+H).
Normalize Whitespace: Trim line edges and reduce blank runs (Ctrl+Shift+Enter).
Join Lines: Join lines in the paragraph or selection (Ctrl+Shift+J).
Hard Line Break: Reflow the paragraph or selection (Ctrl+Shift+H).
Strip Markdown Tags: Remove Markdown tags (Ctrl+Shift+M).
Order Items: Sort the paragraph or selection lines (Alt+Shift+O).
Keep Unique Items: Remove duplicate lines in the paragraph or selection (Alt+Shift+K).
Reverse Items: Reverse the lines in the paragraph or selection (Alt+Shift+Z).
Quote Lines: Add a prefix to lines in the paragraph or selection (Ctrl+Q).
Unquote Lines: Remove the prefix from lines in the paragraph or selection (Ctrl+Shift+Q).
Text Statistics: Show characters, words, and lines for the selection or document (Alt+Y).
Spellcheck Navigation: F7 previous error, F8 next error.

View:
Show voices in editor: Show voice system, voice list, and multilingual filter.
Show favorite voices: Show the favorite voices list in the editor.
Text color: Change the text color (including light and dark colors).
Text size: Change the text size (small, normal, large, extra large, extra extra large).
When the list of entries is visible, pressing Tab moves the focus between the editor and the controls, while Shift+Tab moves it backward.
To add or remove an entry from favorites, use Tab to move to the list of entries and add or remove it using the Applications key or the right mouse button. From the list of favorite entries, you can also press the Applications key to remove entries that have already been added.
Keyboard shortcuts: Press F9 and F10 to switch between entries during reading, cycling through those added to favorites.

Bookmarks:
Insert Bookmark: Save the current cursor position or audiobook time (Ctrl+B).
Manage Bookmarks: View, jump to, or delete saved bookmarks. When opening a file with bookmarks, the cursor or playback will automatically resume from the first available one.

Voice and audio:
Reading: F5 Start Reading, F4 Pause/Resume, F6 Stop Reading.
Previous sentence: Shift+F5 jumps to the previous sentence during reading.
Next sentence: Ctrl+F5 jumps to the next sentence during reading.
Favorites during reading: F9 previous favorite voice, F10 next favorite voice.
Record Audiobook: Create an MP3 file from the current text (Ctrl+R).
Batch Audiobooks: Convert a list of files into audiobooks (Ctrl+Shift+B).
Record Podcast: Record a podcast from microphone and/or system audio (Ctrl+Shift+R).
Convert Audio: Convert audio/video files to other audio formats (Ctrl+Shift+A).
Execute file: runs the current file with the configured interpreter (Ctrl+Shift+F5).

Tools:
Batch Audiobooks: Opens a window to convert a list of files (or entire folders) into audiobooks.
- Add files/folders to the queue.
- Choose destination folder and format (MP3 or WAV).
- Options to create subfolders and avoid overwrites.
- Press Start to process everything in the background.
Dictionary: Opens the dictionary window. The list is navigated with Up/Down arrows.
Tab moves to the "Add entries to dictionary" button, activated with Enter or Space.
In the add/edit window: enter "Original word", then Tab to "Replacement word", then OK or Cancel (Enter/Space). ESC cancels.
In the list, Tab moves to "Edit entry" and "Remove selected entry".
Dictionary replacements are applied during reading and audiobook creation and are saved automatically.
Import YouTube transcript: paste a URL, choose the language, and import the text into the editor (Ctrl+Y). Optional timestamps.
Search and import from Wikipedia: search for an article on Wikipedia and import its text into the editor (Alt+Shift+W).
Online dictionary: search for definitions and translations in the online Wiktionary (Alt+Shift+D).
Play Streaming Audio (Alt+Shift+S): Plays audio from streaming websites such as YouTube, allows you to choose the format and quality, and lets you listen without downloading (for example, for online radio).

Worldwide Radio (Alt+Shift+R): Opens the window to search for and listen to online radio stations from different countries. You can search for radio stations by name, country, language, and genre. From the results list, press Enter to start playing the selected radio station. You can add a radio station to favorites, so you can find it more easily later. Sonarpad also lets you add local radio stations to the shared program database, so other users can find and listen to them too. When adding a radio station, you must enter at least the radio name and the streaming address.

Routes and navigation (Alt+Shift+N): Opens the window to calculate a route between two addresses. Enter the starting point and the destination, then choose the travel mode: walking, cycling, driving, or wheelchair. You can choose the route type, fastest or shortest. For driving routes, you can also choose whether to avoid highways, tollways, or both. You can enable the option to include the municipalities crossed in the result. After calculation, Sonarpad shows the main route and, when available, alternative routes too. The route is imported into the editor as text, with starting point, destination, distance, estimated duration, and step-by-step directions. When a route map is available, you can save the visual map as a PNG image from the File menu, Save image.

Accessible Terminal: Opens a dedicated terminal with stable output for screen readers (Ctrl+Shift+T).
Shortcuts: Alt+I focuses input, Alt+O focuses output, Tab/Shift+Tab moves between input, output, and options.
Enter sends the input. Ctrl+C copies the output (or sends Ctrl+C to the program). Ctrl+L clears the output with confirmation.
Terminal options: auto-scroll, strip ANSI codes, announce new lines, beep after 1 s idle, prevent sleep.
Program choices: Command Prompt (cmd.exe), PowerShell, Codex CLI (from Options).

RSS / Articles: Opens the RSS/Articles window. Add sources, expand a feed, and press Enter to import an article into the editor.
In the RSS window, select a feed or site and press Delete to remove it from the library.
From the context menu of a feed or site, you can edit or delete the RSS source or site.
After importing an article, press Esc to return to the RSS list.
Podcasts: Opens the Podcasts window to search and manage subscriptions.
In the episode list, press Enter to play the episode.
During playback, Esc stops the podcast and returns to the library.

AI audio description:
With this feature you can audio-describe any video content. As someone who loves audio description, this is a feature I care about very much, and I am releasing it to the public because it has reached a level that I consider satisfactory. There are also paid services that offer similar features; if Sonarpad is useful to you, I invite you to support my work. This feature has also been tested in real use with hundreds of films and series.

Another problem addressed by Sonarpad concerns content that Gemini considers violent or sensitive. Some methods may refuse to describe entire scenes, sometimes because of false positives. Sonarpad instead tries to handle these cases by asking Gemini to phrase the description in a way that is compatible with its policies: if a detail cannot be described explicitly, it is omitted or expressed less graphically instead of giving up on the entire scene.

A fundamental feature is silence management: the synthesized voice must not speak over dialogue. For this reason, as a first step Sonarpad analyzes the audio and looks for the moments in which the audio description can speak without disturbing the listening experience.

The feature has been tested with hundreds of films and series, and over time many of the inaccuracies that Gemini can make have been corrected, for example synchronization between what happens on screen and the description. Naturally, the result also depends on external services, so I cannot guarantee that every description in every film will always be perfect. I continue to work on improving Sonarpad and therefore this feature as well.

When you open the feature, you will find the Local media file field, initially empty, followed by the Choose video button. Activate this button with Space to select the video you want to audio-describe.

After you choose the video, Sonarpad automatically fills in the path of the Destination MP3 file. With Tab you can reach this field and change the path, or use the Change destination folder button.

Press Tab again to change the audio-description language. The choice is consistent with Sonarpad and includes all languages currently supported by the program.

Next you will find Audio-description brevity. The default value is Detailed because, in my tests, it gives a good result especially in films with long silent scenes. You can still choose any of the other available levels.

With Tab you will then find Enable extended pauses. It is disabled by default. It can be useful in films with a lot of dialogue, fast-paced scenes, or very little free space for the audio description to speak. In exceptional cases Sonarpad can briefly pause the film to insert a description that would not otherwise fit inside a silence.

The Try to recognize characters and use their names check box lets Sonarpad try to say a character's name in the audio description. If it is disabled, descriptions remain more generic, for example “the man approaches” or “the woman enters”. Recognition is handled by Gemini and cannot be guaranteed in every case: similar-looking characters, unclear shots, or difficult images can cause identity mistakes.

Press Tab again to find Keep the character catalog. This is especially useful when audio-describing a series because it lets Gemini preserve character descriptions and identities from one episode to the next. If no catalog exists yet, choose Create a new catalog and enter its name in the following field, for example the title of the series.

Sonarpad stores character information in the catalog to improve recognition continuity. You can also start from a sample catalog created by Sonarpad, copy it into another AI, and ask it to complete the catalog with descriptions for the series you are interested in. The resulting catalog must remain in JSON format and can be copied to Documents\Sonarpad\Audiodescriptions\Catalogs. This lets you start a series with an already prepared catalog.

Press Tab again to find Also save the project for future editing. Enable it when you know that you will later want to review the audio description, correct descriptions, or change the voice.

The Create audio description on the original video file check box lets you obtain a video file with the audio description already inserted, instead of only an MP3 file. When this option is enabled, Sonarpad keeps the original video and adds the generated descriptions to its audio track without unnecessarily re-encoding the video. The default format is MP4, but you can also choose MKV in the save window. The original video file is never overwritten.

When you create the audio-described video directly, extended pauses are not used because they would change the duration and synchronization of the film. Sonarpad therefore inserts descriptions only into the spaces available in the original audio track.

The Move the video file to the Recycle Bin after the audio description check box is useful if you do not want to keep the original video after the audio-described MP3 has been created. It is disabled by default and is available when project saving is not enabled, because an editable project still needs the original video.

Next you will find Gemini API key. Enter your API key here. The key can be created for free. With Tab you reach the Get API key button, which opens the Google page in your browser where, after signing in with your account, you can create the key. The procedure is normally very quick.

After the API key you will find Gemini model and the Refresh model list button. In most cases you can leave the already selected model unchanged; refresh the list when you want to check which models are available for your key.

Press Tab again to find Speech synthesis engine and Voice, which you can change according to your preferences.

Further on you will find Modify audio-description project. This feature lets you reopen and edit a project that you previously saved. Important: to modify the project, the original video file must still be available.

The Modify audio-description project window also includes Reanalyze segment. This feature is useful when one or more descriptions in part of a film do not satisfy you and you want Gemini to analyze that area again without recreating the entire audio description.

Select a description that belongs to the area you want to review and activate Reanalyze segment. Sonarpad analyzes the video segment containing that description again and proposes new text while keeping the timings and available spaces already saved in the project. When reanalysis finishes, the new voice previews for the segment are already prepared: move among the descriptions and press Space to hear them immediately together with the original audio.

The affected descriptions are marked as segment reanalyzed. The reanalysis remains a proposal until you choose Apply segment and re-export MP3. Only then does Sonarpad apply the new descriptions to the project and recreate the audio-described file. If you do not apply the segment, the saved project remains unchanged.

Next you will find Continue interrupted audio description. Sonarpad is designed not to lose work that has already been completed: if the connection drops during creation, Gemini has a problem, or the process is interrupted, Sonarpad periodically saves progress checkpoints. With this feature you can resume an unfinished job without starting again from the beginning.

Finally you will find Create audio description. If you have not entered a valid Gemini API key, Sonarpad will show an error. If everything is configured correctly, the process will start. The duration depends mainly on the length and complexity of the video: processing a long film can take a considerable amount of time.

Options
The Options window allows you to customize the behavior of Sonarpad. Settings are divided into different tabs.
General Tab
Interface language: lets you choose the language of the program.
File opening (new tab / new window): with New tab you can switch between open files using Ctrl+Tab. With New window you can switch between windows using Alt+Tab.
Check for updates at startup: automatically checks for updates when the program starts.
Send anonymous crash reports: automatically sends anonymous error reports to the program author.
Add to context menu “Open with Sonarpad”: adds an entry in File Explorer to open files directly with Sonarpad.
File associations: opens the Windows dialog to manage file associations supported by Sonarpad.
Global proxy: allows you to configure a proxy to be used for all program connections.
Voice Tab
TTS Engine (Microsoft / SAPI5 / SAPI4): lets you choose the speech engine used during reading.
Main voice: allows you to select the voice used for reading the text. For Edge voices, a second field is available to filter voices by language and the “Multilingual voices only” option.
Voice preview: plays a sample of the selected voice.
Pitch, speed and volume: allow you to adjust these parameters.
Different voice for dialogues: if enabled, allows a different voice to be used for dialogue parts.
First dialogue voice (optional): allows you to set a specific voice for dialogues.
Second dialogue voice (optional): allows you to add a second voice for dialogues.
If enabled, Sonarpad can use up to three different voices.
Editor Tab
Automatic line wrap: enables or disables automatic line wrapping.
Line width: sets the maximum number of characters per line.
Smart quotes: automatically replaces straight quotes with typographic quotes.
Spell check: enables the spell checker for the current language.
Dictionary translation language: sets the target language for the online dictionary.
Wikipedia language: selects the language used for Wikipedia searches.
Audio Tab
Forward/backward jump interval: defines how many seconds to skip forward or backward during playback.
Default audiobook folder: sets the destination folder for generated audiobooks.
Audiobook splitting: no split, split by text, split into a specific number of parts, or split by duration.
Subtitle options: allows you to choose how subtitles are handled during media playback.
RSS and Podcast Tab
Podcast cache limit: defines the maximum space used for downloaded podcasts.
Podcast Index (API key / API secret): enter credentials for Podcast Index.
Confirm RSS/Podcast deletion: shows a confirmation message before deleting items.
Unread/unplayed status announcement: indicates whether an item has been read or played.
Date/time display: allows customization of date and time display.
Quick RSS copy: lets you choose what is copied with Ctrl+C.
Shortcuts Tab
List of commands with editable shortcuts.
Record new key combination.
Restore default shortcuts.
Window: opens the Window menu.
Open Documents...: shows the list of open documents.
Close Others: closes all documents except the active one.
Close All: closes all open documents.

Help:
Guide: Open this guide (F1).
Check for updates: Check if updates are available (F2).
Changelog: Opens the changelog window.
About: Shows program information.
