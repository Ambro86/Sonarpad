使用指南

文件：
新建：创建新文档（Ctrl+N）。
打开：打开文本文件、PDF、EPUB、MP3及其他支持的格式（Ctrl+O）。
保存：保存文档（Ctrl+S）。
另存为：以新名称保存。
全部保存：保存所有文档（Ctrl+Shift+S）。
最近使用的文件：打开最近使用的文件。

多媒体文件：
当您打开多媒体文件（MP3、WAV、MP4、AVI）时，Sonarpad 会变成一个音频播放器。
键盘控制：
- SPACE：播放/暂停。
- 右箭头：快进1分钟。
- 左箭头：倒退1分钟。
- 上箭头键：调高音量。
- 下箭头：降低音量。
- +：加快播放速度。
- -：降低播放速度。
- SHIFT +: 提高音高。
- SHIFT -: 降低音高。
- CTRL+I：播报当前播放时间。
- CTRL+T：跳转至特定时间点。
- CTRL+B：在精确时间处插入书签。

分割当前媒体文件：
当打开本地多媒体文件时，可以在“播放”菜单中使用“分割媒体”功能。
文件可以通过两种方式分割：
- 按部分分割：选择要将文件分成多少部分，范围为 2 到 999。
- 按时间分割：选择每一部分的时长，格式可以是秒、mm:ss 或 hh:mm:ss。
此功能适用于本地文件，例如 MP3、MP4 以及其他支持的格式。
分割过程中，Sonarpad 会以百分比显示进度。
完成后，生成的文件会保存到程序显示的文件夹中。

编辑：
撤销：撤销上一步操作（Ctrl+Z）。
剪切：删除选定文本并将其复制到剪贴板（Ctrl+X）。
复制：将选定文本复制到剪贴板（Ctrl+C）。
粘贴：将剪贴板内容粘贴到文档中（Ctrl+V）。
全选：选中所有文本（Ctrl+A）。
查找：在文档中搜索文本（Ctrl+F）。
在多个文件中查找：在多个文件中搜索文本（Ctrl+Shift+F）。
查找下一个：查找下一个出现位置（F3）。
替换：查找并替换文本（Ctrl+H）。
规范化空格：删除行首和行尾空格，并压缩连续空格（Ctrl+Shift+Enter）。
合并行：将段落或选定内容中的多行合并为一行（Ctrl+Shift+J）。
重新排版：重新调整段落或选定文本的换行格式（Ctrl+Shift+H）。
移除 Markdown 标签：删除 Markdown 标签（Ctrl+Shift+M）。
排序项目：对段落或选定行进行排序（Alt+Shift+O）。
保留唯一项目：删除段落或选定内容中的重复行（Alt+Shift+K）。
反向项目：反转段落或选定内容中的行（Alt+Shift+Z）。
添加引用前缀：为段落或选定文本中的每行添加前缀（Ctrl+Q）。
移除引用前缀：删除段落或选定文本中每行的前缀（Ctrl+Shift+Q）。
文本统计：显示所选内容或文档的字符、单词和行数（Alt+Y）。
拼写检查导航：F7 上一个错误，F8 下一个错误。

查看：
在编辑器中显示语音：显示语音系统、语音列表及多语言过滤器。
显示收藏语音：在编辑器中显示收藏语音列表。
文本颜色：更改文本颜色（浅色/深色主题）。
文字大小：更改文字大小（小、正常、大、特大、超大）。
当条目列表可见时，按Tab键可在编辑器和控件之间移动焦点，而Shift+Tab键则向后移动焦点。
要将条目添加至收藏夹或从收藏夹移除，请使用Tab键移动至条目列表，然后通过应用程序键或鼠标右键进行添加或移除操作。在收藏夹条目列表中，您也可按下应用程序键移除已添加的条目。
键盘快捷键：阅读时可按F9和F10在条目间切换，循环浏览已添加至收藏夹的条目。

书签：
插入书签：保存当前光标位置或有声书时间（Ctrl+B）。
管理书签：查看、跳转或删除已保存的书签。打开包含书签的文件时，光标或播放会从第一个可用书签位置继续。

语音与音频：
阅读：F5 开始阅读，F4 暂停/继续，F6 停止阅读。
上一句：Shift+F5 在阅读时跳到上一句。
下一句：Ctrl+F5 在阅读时跳到下一句。
阅读时收藏语音切换：F9 上一个收藏语音，F10 下一个收藏语音。
录制有声书：将当前文本生成 MP3 文件（Ctrl+R）。
批量有声书：将文件列表转换为有声书（Ctrl+Shift+B）。
录制播客：通过麦克风和/或系统音频录制播客（Ctrl+Shift+R）。
音频转换：将音频/视频文件转换为其他音频格式（Ctrl+Shift+A）。
使用解释器执行文件：用已配置的解释器运行当前文件（Ctrl+Shift+F5）。

工具：
批量有声书：打开一个窗口，将文件列表（或整个文件夹）转换为有声书。
- 将文件/文件夹添加到队列中。
- 选择目标文件夹和格式（MP3 或 WAV）。
- 创建子文件夹并避免覆盖的选项。
- 按下开始键，在后台处理所有内容。
词典：打开词典窗口。通过上/下箭头键浏览词条列表。
Tab键移动至"将条目添加至词典"按钮，按Enter键或空格键即可激活。
在添加/编辑窗口中：输入"原始词语"，然后按Tab键切换至"替换词语"，接着点击确定或取消（Enter/空格键）。ESC键取消操作。
在列表中，Tab键可移动至"编辑条目"和"删除所选条目"。
词典替换在阅读和有声书制作过程中应用，并被保存。
导入YouTube字幕：粘贴URL，选择语言，将文本导入编辑器（Ctrl+Y）。可选时间戳。
从维基百科搜索并导入：在维基百科上搜索文章，将其文本导入编辑器（Alt+Shift+W）。
在线词典：在在线维基词典中搜索词义和翻译（Alt+Shift+D）。
播放流媒体音频（Alt+Shift+S）：从 YouTube 等流媒体网站播放音频，可选择格式和质量，并可在不下载的情况下收听（例如用于在线广播）。

来自世界各地的广播（Alt+Shift+R）：打开用于搜索和收听不同国家在线广播电台的窗口。可以按名称、国家、语言和类型搜索广播电台。在结果列表中，按 Enter 播放选中的电台。也可以将电台添加到收藏夹，方便以后快速找到。Sonarpad 还允许将本地广播电台添加到程序的共享数据库中，这样其他用户也可以找到并收听。添加广播电台时，至少需要填写电台名称和流媒体地址。

路线和导航（Alt+Shift+N）：打开用于计算两个地址之间路线的窗口。输入出发地和目的地，然后选择出行方式：步行、骑自行车、开车或使用轮椅。可以选择路线类型：最快或最短。对于驾车路线，还可以选择避开高速公路、收费道路或两者都避开。也可以启用选项，将路线经过的市镇加入结果中。计算完成后，Sonarpad 会显示主路线，并在可用时显示备选路线。路线会作为文本导入编辑器，其中包含出发地、目的地、距离、预计时间和逐步导航说明。如果路线地图可用，可以从“文件”菜单中的“保存图像”将可视地图保存为 PNG。

无障碍终端：打开专用的终端窗口，为屏幕阅读器提供稳定的输出（Ctrl+Shift+T）。
快捷键：Alt+I 聚焦输入框，Alt+O 聚焦输出框，Tab/Shift+Tab 在输入框、输出框和选项之间切换。
按下回车键发送输入。Ctrl+C复制输出内容（或向程序发送Ctrl+C）。Ctrl+L清除输出内容并进行确认。
终端选项：自动滚动，清除ANSI字符，提示新行，闲置1秒后蜂鸣，禁止休眠。
终端类型：命令提示符（cmd.exe）、PowerShell、Codex CLI（可在选项中选择）。

RSS / 文章：打开RSS/文章窗口，添加来源，展开订阅源，按Enter键将文章导入编辑器。
在RSS窗口中，选中一个订阅源或站点，按下删除键即可将其从库中移除。
在订阅源或网站的上下文菜单中，您可以编辑或删除RSS源或网站。
导入RSS文章后，按Esc键返回RSS列表。
播客：打开播客窗口以搜索和管理订阅。
在剧集列表中，按下回车键即可播放该剧集。
播放时按Esc键可停止播客并返回媒体库。

使用 AI 创建音频描述：
通过此功能，您可以为任何视频内容创建音频描述。由于我本人非常喜欢音频描述，因此我非常重视这项功能，并在它达到我认为令人满意的水平后将其公开提供。市面上也有提供类似功能的付费服务；如果 Sonarpad 对您有帮助，欢迎支持我的工作。此外，这项功能已经在数百部电影和剧集中进行过实际测试。

另一个已经处理的问题，是 Gemini 可能把某些内容判断为暴力或敏感。一些方法可能因此拒绝描述整个场景，有时甚至只是误判。Sonarpad 会尝试让 Gemini 以符合其政策的方式重新组织描述：如果某个细节无法直接描述，就会省略该细节或使用不那么直白的表达，而不是放弃整个场景的描述。

一个非常重要的特性是对静音时段的管理：合成语音不应盖住对白。因此在第一阶段，Sonarpad 会分析音频，并寻找音频描述可以播放而不会影响对白收听的时段。

该功能已经使用数百部电影和剧集进行测试，并且随着开发不断修正 Gemini 可能出现的多种不准确情况，例如屏幕上发生的事情与描述时间不同步。由于结果也依赖外部服务，因此我无法保证每一部电影中的每一条描述始终完美。不过我会继续改进 Sonarpad，也会继续改进这项功能。

打开此功能后，首先会看到最初为空的“本地媒体文件”输入框，随后是“选择视频”按钮。把焦点移到该按钮后按空格，即可选择要创建音频描述的视频。

选择视频后，Sonarpad 会自动填写“目标 MP3 文件”的路径。使用 Tab 可以移动到该字段并修改路径，也可以使用“更改目标文件夹”按钮。

再次按 Tab 可以更改音频描述语言。语言列表与 Sonarpad 保持一致，并包含程序目前支持的所有语言。

接下来是“音频描述简洁程度”。默认值为“详细”，因为在我的测试中，它尤其适合包含较长静音场景的电影。当然，您也可以选择其他可用级别。

继续按 Tab 会找到“启用扩展停顿”。此选项默认关闭。对于对白很多、场景节奏很快或几乎没有足够静音空间播放音频描述的影片，它可能很有用。在特殊情况下，Sonarpad 可以短暂暂停影片，以插入原本无法放入静音时段的描述。

“尝试识别人物并使用其姓名”复选框允许 Sonarpad 尝试在音频描述中说出人物姓名。如果关闭此选项，描述会更加通用，例如“男人走近”或“女人进入房间”。人物识别由 Gemini 完成，无法保证所有情况下都完全准确：外貌相似的人物、不清晰的镜头或较难辨认的画面都可能造成身份混淆。

再次按 Tab 会找到“保留角色目录”。在为系列节目制作音频描述时，这项功能尤其有用，因为它允许 Gemini 在不同剧集之间保持人物描述和身份的一致性。如果还没有目录，请选择“创建新目录”，然后在下一个字段中输入目录名称，例如剧集名称。

Sonarpad 会把人物信息保存到目录中，以提高识别的连续性。您也可以从 Sonarpad 生成的示例目录开始，把它复制到其他 AI 中，并要求该 AI 补充您所需要的剧集人物描述。最终目录必须保持 JSON 格式，并可复制到 Documents\Sonarpad\Audiodescriptions\Catalogs 文件夹。这样就可以使用已经准备好的角色目录开始处理一部系列剧。

再次按 Tab 会找到“同时保存项目以便以后修改”。如果您知道以后还要检查音频描述、修正描述内容或更改声音，请启用此选项。

“在原始视频文件中创建音频描述”复选框可以直接生成已经加入音频描述的视频文件，而不仅仅生成 MP3。启用此选项后，Sonarpad 会保留原始视频，并把生成的描述加入其音轨，而不会不必要地重新编码视频。默认格式为 MP4，但在保存窗口中也可以选择 MKV。原始视频文件绝不会被覆盖。

直接创建带音频描述的视频时，不会使用扩展暂停，因为这会改变影片的时长和同步。因此，Sonarpad 只会把描述插入原始音轨中可用的空白位置。

“音频描述完成后将视频文件移到回收站”复选框适用于在创建带音频描述的 MP3 后不想保留原始视频的情况。此选项默认关闭，并且只有在未启用项目保存时才可用，因为可编辑项目仍然需要原始视频。

接下来是“Gemini API 密钥”。请在这里输入您的 API 密钥。密钥可以免费创建。使用 Tab 可以移动到“获取 API 密钥”按钮，该按钮会在浏览器中打开 Google 页面；登录您的账号后即可创建密钥。通常这个过程非常快。

在 API 密钥之后会找到“Gemini 模型”和“刷新模型列表”按钮。通常可以保留当前已经选择的模型；如果想检查您的密钥可以使用哪些模型，可以刷新列表。

再次按 Tab 会找到“语音合成引擎”和“声音”，您可以根据个人喜好进行更改。

继续向后会找到“修改音频描述项目”。这项功能允许重新打开并编辑以前保存的项目。请注意：要修改项目，原始视频文件必须仍然可用。

在“修改音频描述项目”窗口中还提供“重新分析片段”。当影片某一部分的一条或多条描述不令人满意，而您希望让 Gemini 重新分析该区域、又不想重新创建整部影片的音频描述时，这项功能很有用。

请选择属于要检查区域的一条描述，然后启用“重新分析片段”。Sonarpad 会重新分析包含该描述的视频片段，并在保留项目中已经保存的时间和可用空白位置的前提下提出新的文本。重新分析完成后，该片段的新语音预览已经提前准备好：您可以在各条描述之间移动，并按空格键立即与原始音频一起试听。

受影响的描述会标记为“片段已重新分析”。在您选择“应用片段并重新导出 MP3”之前，重新分析的结果只是一项建议。只有在这一步之后，Sonarpad 才会把新描述应用到项目并重新创建带音频描述的文件。如果不应用该片段，已保存的项目将保持不变。

随后是“继续中断的音频描述”。Sonarpad 的设计目标是不丢失已经完成的工作：如果创建过程中网络中断、Gemini 出现问题或流程被停止，Sonarpad 会定期保存进度检查点。通过这项功能，可以从中断位置继续工作，而不需要从头开始。

最后会找到“创建音频描述”。如果没有输入有效的 Gemini API 密钥，Sonarpad 会显示错误。如果一切配置正确，处理流程就会开始。所需时间主要取决于视频的长度和复杂程度；处理一部长片可能需要较长时间。

选项
“选项”窗口允许您自定义 Sonarpad 的行为。设置分为不同的选项卡。
常规
界面语言：允许选择程序的语言。
文件打开方式（新标签页 / 新窗口）：选择“新标签页”时，可使用 Ctrl+Tab 在已打开的文件之间切换。选择“新窗口”时，可使用 Alt+Tab 在窗口之间切换。
启动时检查更新：在程序启动时自动检查更新。
发送匿名崩溃报告：自动向程序作者发送匿名错误报告。
添加到右键菜单“使用 Sonarpad 打开”：在文件资源管理器中添加选项，可直接使用 Sonarpad 打开文件。
文件关联：打开 Windows 窗口，用于管理 Sonarpad 支持的文件关联。
全局代理：允许配置代理服务器，用于程序的所有网络连接。
语音
TTS 引擎（Microsoft / SAPI5 / SAPI4）：允许选择用于朗读的语音引擎。
主语音：选择用于朗读文本的语音。对于 Edge 语音，提供按语言筛选的附加字段，以及“仅多语言语音”选项。
语音预览：播放所选语音的示例。
音高、语速和音量：允许调整这些参数。
对话使用不同语音：启用后，可为对话部分使用不同的语音。
第一对话语音（可选）：为对话设置一个特定语音。
第二对话语音（可选）：为对话添加第二个语音。
启用后，Sonarpad 最多可使用三种不同的语音。
编辑器
自动换行：启用或禁用自动换行。
行宽：设置每行的最大字符数。
智能引号：自动将直引号替换为排版引号。
拼写检查：启用当前语言的拼写检查。
词典翻译语言：设置在线词典的目标语言。
维基百科语言：选择用于维基百科搜索的语言。
音频
前进/后退跳转间隔：设置播放时跳转的秒数。
默认有声书文件夹：设置生成的有声书保存位置。
有声书分割：不分割、按文本分割、按指定部分数量分割或按时长分割。
字幕选项：允许选择在播放媒体文件时如何处理字幕。
RSS 和 播客
播客缓存限制：设置下载播客所使用的最大空间。
Podcast Index（API key / API secret）：输入 Podcast Index 的凭据。
确认删除 RSS/播客：删除项目之前显示确认消息。
